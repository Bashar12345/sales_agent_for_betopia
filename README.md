# Sales Agent for Betopia

## Overview
This project implements a sales agent system for Betopia, designed to assist with sales operations and customer interactions.

## Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd sales_agent_for_betopia
   ```

2. Set up the virtual environment:
   ```bash
   python -m venv agent_env
   source agent_env/bin/activate  # On Windows: agent_env\Scripts\activate
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage
Run the sales agent:
```bash
python main.py
```
